# NovaCartAI

Luxury AI-Powered Ecommerce Marketplace

## Overview

NovaCartAI is a premium AI-driven ecommerce platform designed with a luxury editorial aesthetic. The platform includes:

* Elegant customer storefront
* Seller dashboard
* Admin dashboard
* AI-inspired analytics and recommendations
* Modern ecommerce workflows

The project is built using React, TypeScript, TailwindCSS, and shadcn/ui.

---

# Features

## Customer Experience

* Luxury landing page
* AI-curated product recommendations
* Product collections
* Wishlist
* Cart & checkout
* Order tracking
* User profile
* Responsive design

## Seller Dashboard

* Product management
* Inventory tracking
* Order management
* Revenue analytics
* Customer reviews
* Seller insights
* AI-powered recommendations

## Admin Dashboard

* Seller approvals
* Product management
* Customer management
* Category management
* Platform analytics
* Order monitoring
* Revenue tracking

# Installation

## Clone Repository

bash
git clone <your-github-repo-url>
cd novacartai


## Install Dependencies

bash
npm install


## Start Development Server

bash
npm run dev


Application will run at:

bash
http://localhost:8080


---

# Build for Production

bash
npm run build
